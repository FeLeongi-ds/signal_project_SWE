# Part 3 Coverage Notes

The JaCoCo report was generated by running `mvn test`.

The Part 3 code is tested for patient data storage, record filtering,
file-based data reading, and alert generation. The tests cover normal and edge
cases, including malformed file input, blood pressure alerts, oxygen saturation
alerts, hypotensive hypoxemia, ECG peak detection, and triggered alert records.

Some original simulator infrastructure is not covered, including console, TCP,
and WebSocket output behavior and the scheduled simulator loop. These parts
depend on runtime I/O, networking, or long-running execution, so they are better
suited to manual or integration testing.
